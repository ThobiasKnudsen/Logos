12. WRONG UNIFORM DECLARATION IN SHADERS ⭐⭐⭐⭐⭐
    Location: shaders.zig:182 and gpu_pipeline.zig:345-357

    THE REAL BUG:
    The shaders used Vulkan-style push constants:
    ```glsl
    layout(push_constant) uniform PushConstants { ... }
    ```

    But SDL3 GPU API uses **uniform buffers**, NOT Vulkan push constants!
    Should be:
    ```glsl
    layout(binding = 0, std140) uniform PushConstants { ... }
    ```

    AND the shader creation must specify num_uniform_buffers = 1!

    Why this explains ALL symptoms:
    - CPU logs showed correct values: primary_color = (1, 1, 1) WHITE
    - GPU rendered GREEN (0, 1, 0) garbage
    - Test 7: Shader outputs `primary_color.rgb` directly
    - Result: GREEN instead of WHITE
    - Conclusion: Push constants not reaching GPU!

    The Problem:
    1. Shader declared `layout(push_constant)` - SDL3 doesn't support this
    2. Shader creation used num_uniform_buffers = 0 (default)
    3. SDL_PushGPUFragmentUniformData sent data to slot 0
    4. GPU had no uniform buffer declared, read garbage memory

    THE FIX:
    1. Change shader to: `layout(binding = 0, std140) uniform PushConstants { ... }`
    2. Change shader creation to specify: `num_uniform_buffers = 1`

    Files Changed:
    - src/renderer/shaders/shaders.zig (line ~182, ~214)
    - src/renderer/gpu_pipeline.zig (lines 345-357)

================================================================================
FINAL SOLUTION
================================================================================

The root cause was **WRONG GLSL UNIFORM DECLARATION SYNTAX**:

**THE BUG:**
Shaders used Vulkan-style push constants:
```glsl
layout(push_constant) uniform PushConstants { ... }
```

But SDL3 GPU API doesn't support Vulkan push constants!
SDL3 uses descriptor set-based uniform buffers.

**THE FIX:**
Changed to SDL3-compliant syntax:
```glsl
layout(set = 3, binding = 0, std140) uniform PushConstants { ... }
```

**Why this syntax:**
- `set = 3`: SDL3 convention for fragment shader uniforms
- `set = 1`: SDL3 convention for vertex shader uniforms (different set!)
- `binding = 0`: Maps to SDL_PushGPUFragmentUniformData slot 0
- `std140`: Standard uniform buffer layout convention
- Must also set `num_uniform_buffers = 1` when creating the shader

**Files Changed:**
1. src/renderer/shaders/shaders.zig (lines ~182, ~214) - template shaders
2. src/lang/glsl_gen.zig (line ~602) - generated shader headers
3. src/renderer/gpu_pipeline.zig (lines ~175-185, ~347-357) - shader creation

**Reference:**
C++ implementation in cpp/src/shader_compiler/shaders/mandelbrot.frag.glsl
uses the same pattern with SPIRV-Reflect for automatic resource detection.

**Test Results:**
- "0" shows BLACK ✓ (scalars work)
- "1" shows WHITE ✓ (scalars work)
- "x<y" shows WHITE with Test 7 ✓ (uniforms work!)
- Now restoring boolean expression evaluation for diagonal line

The shader logic was always correct. The issue was purely the uniform declaration
syntax mismatch between Vulkan push constants and SDL3 descriptor sets.
